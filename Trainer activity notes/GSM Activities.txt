GSM Activities(GSM, LCD,RGB,rotary slider,sensor module)
GSM module general wiring(GSM_RX=17,GSM_TX=16,PWRKEY=4)

1 Getting to know GSM 	---> 	Check network registration status and ensure the SIM800L connects to a mobile network. Ensure simcard has mobile data.
act1 = simcard (must know the number), GSM module

		  		Explain LED Blinking State and how to interpret network statuses.
				Check signal quality (RSSI) periodically and display it over Serial.
				Send SMS with SIM800L using AT command.

  QUICK AT-COMMAND CHEAT-SHEET (type these in Serial Monitor):
  - AT                -> test module (expect OK)
  - AT+CPIN?          -> SIM status (expect +CPIN: READY)
  - AT+CSQ            -> signal quality (example +CSQ: 15,0)
  - AT+CREG?          -> network registration (example +CREG: 0,1 means registered)
  - AT+CMGF=1         -> set SMS text mode
  - AT+CMGS="+63..."  -> begin SMS send (wait for '>')
  - /send             -> special command in this sketch: sends CTRL+Z (ASCII 26)
